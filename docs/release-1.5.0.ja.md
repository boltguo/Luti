# Luti 1.5.0

- セルフホスト VPS 接続を追加しました。OpenAI、Cloudflare と同時に利用できます。専用 SSH 鍵とサーバー設定スクリプトを自動生成し、暗号化されたリバース SSH トンネルで接続します。OAuth の承認は引き続き Mac 上で行います。
- `project_select` を追加しました。Runtime がアイドル状態のとき、AI は Mac で承認済みのプロジェクトへ共有ワークスペースを切り替えられます。実行中のジョブ、ツール呼び出し、承認待ちの操作がある場合は切り替えません。権限、メモリ、履歴はプロジェクトごとに保持され、古いトークンでは新しいプロジェクトを変更できません。
- 接続設定とプロジェクトの操作を簡素化し、Material 3 Expressive の UI に統一しました。VPS の SSH 設定は常に表示し、セットアップガイドだけを折りたたみます。Cloudflare は初回接続の失敗時に HTTP/2 へフォールバックできます。
- 未設定の接続のスイッチを押すと設定画面へ移動し、スイッチはオフのままになります。有効な設定の保存後にオンになります。設定がないままオンになっていたスイッチもオフに戻します。
- セーフモードで、コードを直接付けたインタープリター引数、Node の `--eval=…` / `--print`、プロジェクトスクリプト内の Git `-C` / `-c` などが承認を回避できる問題を修正しました。ビルドスクリプトによる出力の削除は引き続き利用できます。
- 承認画面に展開可能な詳細を追加しました。機密情報をマスクした完全な引数、作業ディレクトリ、標準入力、プロジェクトスクリプト、指定された環境変数を確認できます。
- 引き継ぎの要約から完了済みのプレビュー操作を除き、実際の変更を残します。選択中のプロジェクトが変わると、開いているプロジェクトの履歴ページも再読み込みします。
- 長いホームディレクトリのパスで SSH 制御ソケットを作成できない問題を修正しました。VPS 設定を保存しても固定済みのホスト鍵を保持し、予期しない鍵の変更を引き続き検出します。
- VPS の導入手順を改善しました。有効な UFW で TCP 80/443 を許可し、クラウド側のルールと証明書発行を説明します。稼働中もガイドを読め、Cloudflare の手順は現在のビルドのローカルポートを表示します。

## アップグレード

**接続中の各 AI クライアントで Luti のツール一覧を更新**するか、コネクタを削除して追加し直してください。`project_select` を含め、ツールは 25 個になりました。切り替え後に変更を行うには、新しいプロジェクトトークンの取得が必要です。

既存のプロジェクト、権限設定、メモリ、履歴、接続設定は保持されます。VPS の設定は任意です。HTTPS と SSH は各通信区間を暗号化しますが、HTTPS を終端する VPS のリバースプロキシは内容を読めます。Cloudflare プロキシを有効にした場合は Cloudflare も同様です。[VPS の設定とセキュリティ](https://github.com/boltguo/Luti/blob/v1.5.0/docs/vps.md)を参照してください。

Apple Silicon 搭載の Mac、macOS 14 以降に対応。ブラウザー自動化には Google Chrome が必要です。
