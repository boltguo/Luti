# Luti 1.5.0

- 新增自托管 VPS 连接，可与 OpenAI、Cloudflare 同时运行。Luti 自动生成专用 SSH 密钥和服务器配置脚本，通过加密的反向 SSH 隧道连接；OAuth 授权仍在 Mac 上确认。
- 新增 `project_select`，允许 AI 在 Runtime 空闲时切换到本机已批准的项目。存在运行中的任务、工具调用或待审批操作时禁止切换。各项目独立保留权限、记忆和活动记录；旧项目令牌不能修改新选中的项目。
- 简化连接设置和项目导航，统一 Material 3 Expressive 界面。VPS 的 SSH 配置直接展示，仅折叠部署教程。Cloudflare 初次连接失败时可回退到 HTTP/2。
- 未配置的连接点击开关后进入设置，开关保持关闭；成功保存配置后才开启。此前误存为开启的未配置连接会恢复关闭。
- 修复安全模式对解释器附着参数、Node `--eval=…` / `--print`，以及项目脚本中 Git `-C` / `-c` 等全局参数的审批漏检。项目构建脚本仍可正常清理自身输出。
- 审批弹窗增加可展开的完整详情，展示脱敏后的命令参数、工作目录、标准输入、项目脚本和传入的环境变量。
- 交接摘要保留真正产生效果的修改，避免被后续预演挤占；切换当前项目后，已打开的项目活动页会重新加载该项目历史。
- 修复较长用户目录路径导致 SSH 控制套接字创建失败的问题。保存 VPS 设置会保留已固定的服务器公钥，意外的密钥变更仍会阻止连接。
- 补齐 VPS 部署流程：为已启用的 UFW 放行 TCP 80/443，区分云防火墙与证书签发，服务运行时仍可阅读教程；Cloudflare 指南自动显示当前构建的本地端口。

## 升级说明

**在每个已连接的 AI 客户端中刷新 Luti 工具列表**，或移除后重新添加连接。工具数量现为 25 个，新增 `project_select`。切换项目后，客户端需要读取新项目令牌才能修改内容。

保留已有项目、权限选择、记忆、活动记录和连接设置。VPS 为可选连接方式。HTTPS 和 SSH 加密各段网络传输；VPS 反向代理可在 HTTPS 终止处读取内容，开启 Cloudflare 代理时 Cloudflare 也可读取。详见 [VPS 配置与安全边界](https://github.com/boltguo/Luti/blob/v1.5.0/docs/vps.md)。

支持 Apple Silicon Mac，要求 macOS 14 或更新版本。浏览器自动化需要 Google Chrome。
