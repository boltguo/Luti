# Luti 1.4.0

- **セーフモード**が復活し、すべてのプロジェクトで既定になりました。`rm`、`mv`、`chmod` などのコマンド、リポジトリの状態を変える Git コマンド、`run_shell`、インタプリタのインラインコード、パスの削除は、このMacで一度承認してから実行されます。プロジェクトページの「フルアクセス」スイッチで承認をオフにでき、実行中でもすぐに反映されます。
- プロジェクトメモリを `memory_query`（`index`、`read`、読み取り専用）と `memory_action`（`write`、`delete`）に分割しました。AIクライアントでのメモリ読み取りに確認は不要になりました。
- メモリの書き込みが無条件に上書きすることはありません。ファイルの置き換えや削除には、クライアントが最後に読み取った `sha256` が必要なため、複数のクライアントが同時に更新しても互いの変更は失われません。置き換え時に省略した名前、説明、種類は以前の値のまま保持されます。
- AIクライアント間の引き継ぎ：複数ステップの作業の前に、AIがチェックリスト付きの `kind=task` メモリファイルを作成します。`project_info` は各タスクの進捗と作成者、すべてのクライアントによる最近の変更を表示するため、前のセッションが途中で止まっても別のセッションが作業を続けられます。
- `runtime_status` は権限モードを報告します。
- ツールを26個から24個に整理しました。`browser_inspect` のアクションは `browser_observe` に、`browser_dialog` の `accept`、`dismiss` は `browser_action` に統合されました。読み取り専用ツールは `projectToken` を受け取りません。
- `git_query`、`path_action`、`edit_files`、`code_query` は他のアクション用の既定値を公開しなくなり、呼び出しが失敗する問題を解消しました。
- `run_process` が `-c` でシェルを起動する場合、`run_shell` と同じコマンドチェックを適用します。

## アップグレード

**接続中の各AIクライアントでLutiのツール一覧を更新してください**。またはコネクタを削除して追加し直してください。`memory`、`browser_inspect`、`browser_dialog` は置き換えられたため、クライアントがツール一覧を再読み込みするまでこれらの呼び出しは失敗します。ツール一覧が変わるたびに、ホーム画面に閉じるまでこの案内が表示されます。

既存のプロジェクトはセーフモードで開きます。以前の動作を維持するには、プロジェクトページで「フルアクセス」をオンにしてください。

1.1、1.2、1.3 で保存したプロジェクト、Tunnel 設定、APIキー、アクティビティ、権限、プロジェクトメモリは保持されます。

macOS 14以降、Appleシリコン搭載Macが必要です。ブラウザ自動化には Google Chrome が必要です。
