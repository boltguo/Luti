Privacy & control

Your Mac. Your rules.

Decide which folder to open, how clients connect, and when the runtime stops.

  • One approved folder at a time Tools operate strictly inside the single project folder you select on your Mac. Switching projects immediately closes active jobs, browser sessions, and artifacts.
  • Direct tunnels, approved on your Mac Connect through your own OpenAI Secure MCP Tunnel or Cloudflare Tunnel with project-bound OAuth and local verification codes. Credentials stay in macOS Keychain.
  • No Luti cloud. Zero repo footprint. Traffic flows directly between your AI client and your Mac. Luti runs no relay servers, requires no account, and never writes runtime metadata into your repository.
  • Off means off Stop the runtime at any time to immediately close all tunnel connections, background processes, and browser sessions.

Get started

Up and running in three steps.

Connect ChatGPT, Claude, Grok, or any remote MCP client in minutes.

  • Select a project folder Download Luti, choose the folder you want to work on in Projects, and start the local runtime.
  • Enable a tunnel connection Turn on OpenAI Secure MCP Tunnel or Cloudflare Tunnel in Connections. Both can run simultaneously.
  • Start a task in your AI client Add Luti in your AI client and ask it to inspect your project, run tests, or check a local preview.

OpenAI Secure MCP Tunnel ChatGPT

Outbound-only private tunnel for ChatGPT workspaces — no public domain or HTTPS endpoint required. Enter your Tunnel ID and Runtime API Key in Luti, then select the tunnel in ChatGPT developer mode.

Cloudflare Tunnel HTTPS · OAuth

Standard remote MCP over your own domain (/mcp) for Claude, Grok, ChatGPT, and other OAuth clients. Every connection is bound to the current project and approved on your Mac with a verification code.
